# 装机工作台 · 视觉方向对照

这组图片使用内置 imagegen 生成，用于比较布局和视觉方向。全部为静态设计稿，价格、配件状态与手动确认状态均为演示数据。不会改变查价原型的实际数据或验证结论。

## 四个方向

| 版本 | 图片 | 布局 | 适合的操作方式 |
|---|---|---|---|
| 原版 | [浅色绿色工作台](workbench-v1.png) | 左导航、中间清单、右候选 | 兼顾完整清单与候选浏览 |
| A | [深色硬件工作台](workbench-v2-dark.png) | 窄图标栏、双栏编辑区 | 偏好深色界面，持续调整配置 |
| B | [浅色紧凑工作台](workbench-v3-compact.png) | 顶部导航、配置表与候选列表并列 | 重视密度、快速比较和反复改配件 |
| C | [卡片式装机向导](workbench-v4-guided.png) | 顶部八件步骤、商品卡片、右侧整单摘要 | 按部件逐步挑选，减少同时处理的信息 |

## 共同交互约定

- 预算 8000 元，七项手动价格合计 3944 元，剩余 4056 元。
- 当前选中显卡槽位，显卡未加入，候选价格不参与合计。
- CPU 已锁定；其他行精简为锁图标，避免重复文字。
- 新增预算数字输入、明确的“加入配置”操作；规格不符的候选收进折叠区。
- 可加入的候选在图中明确标为演示性的“手动已确认”，不能误解为项目已经取得真实自动验证报价。
- 待核实、缺价、接口检查通过、BIOS待确认使用文字与图标一起表达。

这些是生成约束；最终实现仍须用真实组件和数据状态校对，静态图片不能验证按钮逻辑、键盘操作、响应式与屏幕阅读器支持。

## 如何取舍

优先比较信息是否容易找到：能否快速找到总价与剩余预算、确认当前编辑部件、区分可加入与待核实商品，以及在选择候选时仍能看到整单。颜色、圆角与局部组件可以在选定布局后继续调整。

用户明确以视觉效果作为第一标准后，推荐 C 作为后续主稿：商品大图、卡片留白和右侧整单摘要形成更清楚的视觉层级，暖白与深青绿也更协调。C 在这组图里最有完整产品的观感。它的代价是同时展示的候选较少，后续要通过筛选与滚动处理更多商品。

B 的长处是紧凑与编辑效率，A 的长处是深色硬件氛围，原版则较为稳重。按视觉完成度的主观排序为 C、A、原版、B；这个排序不代表可用性测试结果。此次只推荐 C 为主方向，不需要同时实现三套界面。
