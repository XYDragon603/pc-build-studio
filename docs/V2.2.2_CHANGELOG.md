# V2.2.2 更新说明：安全校验与推荐稳定

评分 / 规则版本：`2.2.2`。本版保留 V2.2.1 恢复的高预算推荐（高端显卡不降档），修正散热、供电、物理安装判断中缺少依据的推断，并把必需附件计入完整总价。

## 散热（P0）

- **删除** `coolerSizeClass` / `coolingClassFor`。塔高、冷排尺寸只用于安装检查，不再作为散热能力依据。
- 新增 `src/thermal-evidence.mjs` 散热证据模型，按证据等级判断：
  - **实测**：需有来源、持续 ≥10 分钟、未超温。
  - **厂商标称**：只用于 ≤200W 持续负载。
  - **低功耗工程判断**：按热管数量 / 冷排尺寸，最高 125W。
  - **原装散热**：最高 95W，且需确认所购 SKU 含散热器。
- 证据覆盖不了持续负载时，`cpuCooling` 为关键待核实，并给出可选的降功耗运行条件（限制到证据覆盖的功率）。
- 补件器优先选“证据覆盖负载、安装尺寸已知”的散热器。
- 水冷新增 `radiatorLayoutCheck`：校核冷排位置、厚度（+25mm 风扇）、前置时的显卡可用长度、顶部时的内存空间。

## 必需附件与完整总价（P0）

- 新增 `src/accessories.mjs`。预算、选件、兼容说明、前端与导出共用这一个模型：
  - 按整机热负载确定机箱风扇需求；
  - 预装风扇数量未知时按 0 个保守计价；
  - 单价优先级：机箱记录 > 用户填写 > 工程估算区间（标为估算，不是报价）。
- 方案新增字段：
  - `coreTotalCents`（八件套）；
  - `costBreakdown`（必需 / 可选附件、完整价、估算区间、价格状态）；
  - `additionalCosts` 每项含数量、单价、来源、区间、依据。
- 严格预算和预算状态都按完整总价判断。附件为估算价时，状态为 `met_with_estimated_accessories`，不标为无条件满足。
- API：`POST /plans` 新增 `accessoryPricing: { fanUnitCents?, includedFans? }`（`includedFans` 仅对锁定机箱生效）。
- 机箱排序：阻断项 → 风道依据 → 空间类待核实项 →（>450W）前面板已知为网孔 → 完整成本。
- 修复风扇位计数：同一位置的不同尺寸按二选一取最大，不相加。
- 需要前置进风风扇、而机箱没有说明限长已扣除风扇时，显卡长度要留出 25mm。

## 电源接口与版本（P0）

- `psuConnectors`：原生 16pin 分为有 / 没有 / **未知**，缺失数据不再默认“没有”。插头数与独立线数分开判断。
- 新增可修正字段：`manufacturerModel`、`manufacturerSku`、`hardwareRevision`、`electricalStandard`、`native12vhpwr`、`native12v2x6`、`connectorPowerRating`（150 / 300 / 450 / 600）、`pcie8pinConnectors`、`independentPcieCables`、`cableSource`、`adapterIncluded`。
- 高功耗（≥450W）16pin 显卡：
  - 原生线额定未知 → 待核实；
  - 转接但独立线数未知 → 待核实；
  - 独立线不足 → 不兼容（不能用一线双头凑数）。
- 所有供电说明都提示：只使用原厂配套模组线，禁止混用。
- 电源补件器在 16pin 显卡下优先原生接口。
- 修正记录支持 `requiresRevision`：只有目录名称或料号能确认同一硬件版本时才合并，否则记入 `skippedCorrections`。
- 已核实的数据：
  - 长城 GW-ATX1300BL 目录条目是旧版本，不合并 G13MG（料号 5194268，ATX3.1）规格；
  - 技嘉猎鹰白金 1000PG5 的料号为 GP-EG1000PM PG5，与 GP-AE1000PM 不同，版本未核实。

## 16pin 供电线空间（P0）

- 新增 `gpuCableClearance`：
  - 需求以显卡 / 线材厂商要求优先；否则用 35mm 工程参考值（标明不是统一官方要求）。
  - 空间只认机箱公布的供电线空间或显卡高度限制。
  - CPU 散热器限高只作参考，不能确认空间。
  - 余量 <10mm 或缺少依据、且显卡 ≥300W 时为关键待核实。
- 显卡高度：散热限高只在余量 ≥15mm 时作为参考推断。

## 存储与内存（P1）

- M.2 插槽级模型（`m2Slots` / `storageLink`）：
  - 支持字段：来源（CPU / PCH）、代数、通道、协议、长度、共享通道、禁用端口、依赖 CPU 的限制；
  - 计算预计协商链路，标明“理论值，非装机实测”；
  - 芯片组插槽不再受 CPU 直连链路限制；
  - 缺数据时写出具体缺什么。
- SSD 端点链路改为解析“通道”字段；新增 `m2Length`、`m2Protocol`。
- NAND 按每单元比特数（`bitsPerCell`）规范化，保留原始术语 `nandVendorTerm`。三星 990 PRO 按官方“3-bit TLC”修正。
- `memorySpeedCheck` 分别报告 CPU 规格、主板上限、JEDEC 配置、组合稳定性四项（`factors`）；“在规格内”不等于保证稳定。
- 内存容量价值曲线 `memoryValue`：达到目标后收益递减。新增 `workload.minRamGB`。
- 修复内存频率解析：PC 带宽（如 PC5-51200）不再被当成 MT/s。

## 价格数据（P1）

- 价格合理性过滤：低于中位价一半，且没有 ≥2 条 ±15% 内的同类报价佐证，才视为错价。原规则误删了互相印证的正常低价报价，导致不必要的 64GB 内存，以及 8000 元 2K 推荐版显卡降档。

- 导出的附加费用写明数量、单价来源、估算区间与依据。

## 已知限制

- 散热器没有可读的持续温度实测，>200W 的 CPU 只能标为待验证，或在降功耗条件下使用。
- 机箱显卡高度 / 16pin 线材空间、电源线材额定与独立线数、主板逐插槽 M.2 数据覆盖率很低，相关方案保持“需核实”。
- 风扇单价为工程估算区间，不是报价。
- 4K 光追、AI、剪辑仍为代理性能指标（低可信）。
