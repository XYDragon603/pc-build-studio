# V2.2.1 更新日志

日期：2026-11-26。性质：推荐引擎紧急修复，不做大规模重构，不改界面风格。评分配置版本 `2.2.0` → `2.2.1`。

详细分析（含型号与价格，只在本机）：`reports/v2.2.1/` 下的 ROOT_CAUSE_ANALYSIS.md、DATA_QUALITY_REPORT.md、RECOMMENDATION_DEBUG_REPORT.md、REGRESSION_TEST_REPORT.md 与 batch-results.json。

## 推荐引擎（src/optimizer.mjs、src/recommendation-strategy.mjs、src/scoring-profiles.mjs）

- **取消风险硬过滤**：2.2.0 只要存在无阻断项的组合就剔除其余全部组合；显卡 ≥250W 的整机因机箱缺字段全部带阻断项而被剔除，高预算 AI / 4K 只能选到 250W 以下显卡。现在 FAIL 仍在枚举阶段排除，阻断性待核实项按项扣可信度分并在方案状态标“需核实”。
- **补件器先消除阻断项**：机箱按阻断项数量 → 风道依据 → 价格重新搜索；电源优先长度、规格已知的型号。
- **目标函数**：性价比优先 / 均衡用场景综合评分（含硬盘容量、内存、品质、可信度）减成本惩罚；预算内性能优先先比工作负载核心性能，核心相同再按均衡目标挑其余配件。2.2.0 的“核心性能 − 成本”使硬盘、散热器永远取最便宜。
- **评分曲线**：显卡 / CPU 恢复 2.1 曲线；AI 显卡分改为线性（75% 显存 / 32GB + 25% 算力）。噪音分只来自整机实测；安静优先通过散热档位与电源品质下限生效。
- **散热器选型**：能力（厂商标称已知时 ≥ 负载；尺寸档 ≥ 负载所需）→ 价格 → 证据等级。恢复盒装附带散热器的原装散热选项（仅限确认附带）。
- **显卡候选裁剪**：先剔除没有电源能供电、没有机箱装得下的显卡，再按“显卡 + 最便宜可用电源”做支配比较（穷举测试发现的搜索遗漏）。
- **硬盘容量需求**：默认最低（办公 / 1080p 512GB，2K / 4K / 剪辑 / AI 1TB）与建议容量（办公 / 1080p 1TB，2K / 4K 2TB，剪辑 / AI 4TB）；`workload.minSsdGB` 可调，不足时标明。
- **升级说明**：按实际配置逐项比较显存、显卡指标、CPU 指标、内存、硬盘容量，下降项写原值、新值、原因、收益与是否低于最低要求；删除固定模板。新增方案字段 `tradeoffs`。
- **性能**：机箱尺寸筛选单独缓存、按价格评估到最优即停；主板板型解析缓存。

## 兼容规则（src/compat-rules.mjs、src/hardware-specs.mjs）

- 机箱未公布显卡高度 / 厚度限制、供电线空间、电源限长时，用散热器限高、扩展槽位、16pin 35mm 直线段、ATX 标准电源尺寸做保守推断；推断可装入为 CONDITIONAL 并写明依据，推断不了保持 UNKNOWN 与原阻断级别。机箱公布限制时直接比较（PASS / FAIL）。
- 风道：进 / 排风安装位已知时按整机负载给出风扇数量要求（CONDITIONAL）；位置未知保持 UNKNOWN（高功耗阻断）；没有整机实测永远不是 PASS。
- CPU 持续散热：无实测时按尺寸档的工程判断为 CONDITIONAL；尺寸不足或厂商标称低于负载为 UNKNOWN。
- 内存频率：在 CPU 官方上限内、≤2 条、且为通用频率（DDR4 ≤3200、DDR5 ≤6000，或主板上限已知）时为 CONDITIONAL；按内存类型取上限（Intel 12–14 代 DDR4 / DDR5 不同）。

## 数据（src/platform-data.mjs、src/specs-enrich.mjs、src/catalog-corrections.mjs、data/hardware-corrections.json）

## 商品状态（src/product-status.mjs）

- new / used / refurbished / modified / engineering_sample / unknown。按标题与官方显存表判定；默认推荐只用 new；改装 / 工程样品需 `allowModified: true`（界面“允许改装商品”），二手 / 翻新需 `allowUsed`；规格冲突为 unknown 不参与。目录条目新增 `productStatus`、`productStatusReason`。
